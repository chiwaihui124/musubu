## How to read this

Each thread is tagged by **what would actually close it**, which turns out to be
more useful than a status. A question nobody can answer yet is not the same as one
waiting on a decision somebody could make this afternoon.

| Tag | Means | Who can close it |
|---|---|---|
| `DECIDE` | A judgement call. No new information required. | Anyone on the project, today |
| `RESEARCH` | A fact exists somewhere. Go and get it. | Anyone, or the `fact-checker` agent |
| `JAPANESE` | Needs a native speaker or Japanese-language sources. | A Japanese-speaking collaborator, or `japanese-research` / `translator-ja` |
| `TEST` | Needs real people doing a real thing. | Blocked until something is running |
| `LEGAL` | Needs professional advice, not an opinion. | A lawyer |
| `BUILD` | Resolves itself once the thing is built. | Whoever builds it |
| `ANSWERED` | Closed. Kept so it does not get re-asked. | Done |
